# VISUAL-NOVEL
The Message at 11:11 is an atmospheric web visual novel built with HTML/CSS/JS. Guide Mina through an eerie high school after dark as she uncovers cryptic texts. Features expressive portraits, typewriter text, looping ambient audio, dark visual effects, and choice-driven branching endings.
*The Message at 11:11*
A horror-mystery visual novel built using HTML, CSS, and vanilla JavaScript.
Set late at night in an empty high school, players follow Mina as she receives strange messages from an unknown number, finds hidden notes, and decides whether to investigate or escape.
Features
Dynamic Character Sprites: Portrait automatically swaps between calm and scared expressions as tension rises.
Interactive Choices: Player choices trigger different story branches leading to two unique endings.
Typewriter Effect: Text displays letter by letter for a visual novel reading experience.
Dark Aesthetic: Dark UI styling with vignette overlays, custom typography, and scene transition effects.
Audio Support: Background music starts upon user interaction at the title screen and loops during gameplay.
Tech Stack
HTML5
CSS3
JavaScript (ES6)
Google Fonts (Creepster, Special Elite)
